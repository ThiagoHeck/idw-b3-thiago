# Nome do projeto

Responsividade e Tipografia usando componentes do Bootstrap

## Tema

Uma oficina de robótica fictícia que oferece um curso para iniciantes ou entusiastas (Tinkercad), e outro para profissionais e pessoas que ambicionam áreas de engenharia (AutoCAD).

## Objetivo

O objetivo desse site é experimentar e provar habilidades com responsividade, adaptação do site, uso do Bootstrap e tipografia.

## Páginas do site

AutoCAD.html
Tinkercad.html
carousel_imagem.html
contato.html
formulario.html
index.html

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap
- Google Fonts
- Git e GitHub

## Componentes Bootstrap utilizados

- Navbar
- Forms
- Table
- Carousel

## O que foi adaptado

Foram adaptados os componentes do Bootstrap para melhor se encaixarem com o tema de oficina, como o navbar direcionando para os cursos e a inscrição (o form) e a tabela sendo módulos e horários dos cursos.
